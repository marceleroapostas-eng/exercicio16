\# Exercício 16 - Calculadora



\## Descrição



Este programa solicita dois números ao usuário e apresenta opções de operações matemáticas. O usuário pode escolher entre adição, subtração, multiplicação e divisão. O programa realiza a operação escolhida e exibe o resultado. Também verifica se a divisão por zero foi solicitada e informa caso a operação não seja possível.



\## Tecnologias utilizadas



\- Java



\- NetBeans



\- Maven



\## Entrada



A entrada contém dois números informados pelo usuário e uma opção correspondente à operação desejada.



\## Saída



O programa exibe o resultado da operação escolhida. Caso seja selecionada uma opção inválida ou uma divisão por zero, o programa informa a situação ao usuário.
